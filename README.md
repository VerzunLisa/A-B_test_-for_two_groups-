**A/B-тест: аналіз конверсії**
*Опис проєкту:*
Навчальний проєкт з аналізу результатів A/B-тестування. 
Датасет узятий з Kaggle: https://www.kaggle.com/datasets/sergylog/ab-test-aggregated-data
*Мета*: визначити, яка з двох груп (control / test) дає більшу конверсію з переглядів у кліки, та перевірити, чи є ця різниця статистично значущою.
*Дані*:
Датасет містить 120 000 записів та 4 стовпці:
user_id - унікальний ідентифікатор користувача
group - назва групи: control або test
views - кількість переглядів
clicks - кількість кліків
Дані без пропусків. Групи розділені порівну — по 60 000 користувачів у кожній.
**Хід дослідження**:
EDA - перевірка розмірності, типів даних, пропусків.
Розрахунок CTR (Click-Through Rate) для кожної групи:
CTR_control ≈ 3.47%
CTR_test ≈ 3.85%
Sample Ratio Mismatch (SRM) check — перевірка коректності рандомізації груп (критерій хі-квадрат Пірсона). 
SRM не виявлено (χ² = 0, p = 1) → розподіл користувачів по групах відповідає очікуваному 50/50.
Перевірка нормальності розподілу — візуальний аналіз гістограм views та clicks. 
Розподіли виявились не нормальними.
Статистичний тест — оскільки умова нормальності не виконується, застосовано непараметричний критерій Манна-Вітні:
- розрахунок вручну (сума рангів, U-статистика, Z-статистика);
- перевірка через scipy.stats.mannwhitneyu.
Оцінка величини ефекту — відносний приріст CTR у тестовій групі порівняно з контрольною.

**Результати**:
U-статистика = 1 773 003 355.0
Z-значення = 4.4994
p-value = 8.26 × 10⁻¹³
Приріст CTR (test vs control) = 11,0%

**Висновок**: різниця в конверсії між тестовою та контрольною групами є статистично значущою (p < 0.05). 
Тестовий варіант показує приріст CTR на ~11% відносно контрольного. Рекомендується впровадження тестового варіанту.
